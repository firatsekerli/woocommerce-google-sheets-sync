Sync WooCommerce products with Google Sheets for easy bulk product management and updates.

== Description ==

WooCommerce Google Sheets Sync allows you to manage your WooCommerce products using Google Sheets. Import product data from your Google Sheets directly into WooCommerce with support for bulk operations, scheduled syncing, and real-time updates.

== Features ==

* Connect to Google Sheets via OAuth
* Bulk import products from Google Sheets
* Update existing products
* Scheduled automatic syncing
* Detailed sync logs and error reporting
* Support for product images, categories, and attributes

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/woocommerce-google-sheets-sync/`
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Configure Google API credentials in WooCommerce > Google Sheets Sync
4. Connect your Google Sheets and start syncing

== Requirements ==

* WordPress 5.0 or higher
* WooCommerce 5.0 or higher
* PHP 7.4 or higher
* Google account with Sheets API access
